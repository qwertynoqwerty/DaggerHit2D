# DaggerHit

2D-аркада на Unity, вдохновленная Knife Hit. Игрок бросает кинжалы во вращающуюся цель, собирает яблоки и проходит последовательность этапов, избегая столкновений с уже воткнутыми ножами.

Учебный проект с игровой петлей от стартового экрана до результата и повторного запуска. Основные задачи: физика броска, обработка попаданий, учет ресурсов и переходы между этапами.

## Возможности

- Броски кинжалов в движущуюся цель.
- Вращение цели, столкновения кинжалов и сбор яблок.
- Четыре этапа с обновлением запаса кинжалов.
- Плавные переходы между целями.
- Стартовый экран, счетчики на TextMeshPro, экран результата и повторная игра.

## Техническая реализация

**Стек:** Unity 6, C#, Physics 2D, Input System, Unity UI, TextMeshPro.

| Код | Назначение |
| --- | --- |
| [KnifeThrower.cs](Assets/Scripts/KnifeThrower.cs) | Ввод, создание кинжалов, броски и последовательность этапов |
| [Knife.cs](Assets/Scripts/Knife.cs) | Обработка столкновений кинжала |
| [Apple.cs](Assets/Scripts/Apple.cs) | Сбор яблок |
| [Wood.cs](Assets/Scripts/Wood.cs) | Вращение цели |
| [GameManager.cs](Assets/Scripts/GameManager.cs) | Панели интерфейса, счетчики и завершение игры |

Бросок использует импульс `Rigidbody2D`, а переход между целями реализован корутиной с интерполяцией.

Для знакомства с механикой начните с `KnifeThrower`: в нем видна связь ввода, физики и переходов между целями.

## Запуск

1. Откройте проект в Unity 6000.0.58f2.
2. Откройте сцену **Main** и нажмите **Play**.

## Управление

Нажмите **Start**, затем используйте левую кнопку мыши, чтобы бросать кинжалы. Попадайте в свободные участки цели и собирайте яблоки. Столкновение с уже воткнутым кинжалом завершает игру.
