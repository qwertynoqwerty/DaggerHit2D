**DaggerHit** — учебная 2D-аркада на Unity, вдохновлённая игрой *Knife Hit*.  
Игрок бросает кинжалы во вращающееся бревно, избегает уже воткнутых ножей и собирает яблоки.

Проект создан для практики метания объектов, проверки столкновений, смены этапов, подсчёта очков и базовой игровой логики.

---

## 🎮 Основные возможности

- 🗡 **Метание кинжалов** — игрок бросает кинжалы касанием экрана.
- 🌳 **Вращающееся бревно** — цель меняет скорость вращения на разных этапах.
- 💥 **Проверка столкновений** — попадание в уже воткнутый нож завершает игру.
- 🍎 **Сбор яблок** — игрок получает очки за собранные яблоки.
- 📈 **4 этапа** — каждый этап отличается скоростью вращения бревна.
- 🎨 **Интерфейс** — минималистичные панели и счётчики на TextMeshPro.

---

## 🕹 Как играть

1. Нажмите **Start**, чтобы начать игру.
2. Касайтесь экрана, чтобы метать кинжалы.
3. Попадайте в бревно и избегайте уже воткнутых ножей.
4. Собирайте яблоки, чтобы увеличить счёт.
5. Используйте все кинжалы, чтобы перейти к следующему этапу.
6. Если кинжал попал в другой нож, игра завершается.

## 🚀 Запуск проекта

1. Склонируйте репозиторий:

```bash
git clone https://github.com/qwertynoqwerty/DaggerHit2D.git
```

2. Откройте проект в **Unity 6.0+**.
3. Дождитесь импорта ассетов.
4. Откройте основную сцену проекта.
5. Нажмите **Play**.
